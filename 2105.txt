Maqsad: mavjud aralashib ketgan loyihani noldan tartibli, bitta buyruq bilan ishlaydigan full-stack Django + React platformaga aylantir.

Loyiha nomi: Futbol murabbiylari platformasi / Murabbiy kundaligi.

Asosiy natija:
- `.\start-dev.ps1` buyrug'i bilan backend va frontend birga ishga tushsin.
- Frontend asosiy manzil: `http://127.0.0.1:5173`
- Backend API manzil: `http://127.0.0.1:8000/api`
- Django admin: `http://127.0.0.1:8000/admin`
- Loyiha bitta mahsulot bo'lsin, 2 xil sayt yoki 2 xil UI bo'lib qolmasin.
- `127.0.0.1:8000` faqat API/admin/health uchun ishlasin, asosiy UI faqat React SPA bo'lsin.

Kerakli texnologiyalar:
- Backend: Python, Django, Django REST Framework, SimpleJWT, django-cors-headers, Pillow.
- Local database: SQLite.
- Production uchun tayyorlik: PostgreSQL uchun `DATABASE_URL` qo'llab-quvvatlansin.
- Frontend: React + Vite + TypeScript.
- Router: React Router.
- HTTP client: Axios.
- Icons: lucide-react.
- Styling: bitta tartibli CSS tizimi yoki component-level CSS; eski keraksiz Figma/shadcn/UI dump fayllarini saqlama.

Hisoblash qoidalari:
- Attendance active status faqat `Qatnashdi`.
- attendance_percent = active / total * 100.
- average_rating faqat active records bo'yicha.
- participation_percent = attended_minutes / training_duration_minutes * 100.
- Training duration end_time - start_time, noto'g'ri bo'lsa 90 minut default.
- Team statistics player stats aggregationdan hisoblansin.
- Match result:
  - home_score/away_score yo'q bo'lsa `Rejalashtirilgan`.
  - home_score > away_score bo'lsa `G'alaba`.
  - home_score < away_score bo'lsa `Mag'lubiyat`.
  - teng bo'lsa `Durang`.
