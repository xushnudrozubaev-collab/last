# Coach Platform Frontend

React + Vite frontend.

Root papkadan bitta buyruq bilan ishga tushiring:

```powershell
.\start-dev.ps1
```

Frontend manzili:

```text
http://127.0.0.1:5173
```

Backend API default:

```text
http://127.0.0.1:8000/api
```

API manzilini o'zgartirish kerak bo'lsa `VITE_API_URL` ishlatiladi.
